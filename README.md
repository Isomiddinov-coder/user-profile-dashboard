# User Profile Dashboard

Responsive React + Vite profile card for an internal SaaS admin dashboard.

## Included

- Active / Inactive status toggle with visual indicator
- Edit profile modal with name and role inputs
- Save and Cancel behavior powered by React `useState`
- Avatar image fallback with initials
- Responsive desktop, tablet, and mobile layout
- Semantic HTML, accessible labels, focus states, and Lucide icons

## Run locally

```bash
pnpm install
pnpm dev
```

The app is frontend-only for this component build; profile changes live in local React state.
